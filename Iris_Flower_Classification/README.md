# Iris Flower Classification

## Project Overview

This project is based on the Iris Flower Dataset. The main objective of this project is to build a Machine Learning model that can classify Iris flowers into different species based on their sepal and petal measurements.

The dataset contains three different flower species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

Machine Learning techniques were used to train the model and predict the flower species with high accuracy.

## Dataset Information

The dataset contains the following features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

---

## Machine Learning Model

The Random Forest Classifier model was used for training and prediction.

The model achieved very high accuracy in classifying the flower species.
